## Permission and selection

This skill explicitly requests reviewer delegation. Under a host rule allowing user **or loaded-skill** requests, proceed without a second approval; an unconditional prohibition or actual denial still wins. Delegation permission does not authorize choosing a model. If model overrides require an explicit user model request, omit the optional `model` argument. A suitable inherited-model reviewer may cover the lens but cannot attest cross-model independence. Required unavailable different-model coverage remains incomplete.

Resolve ordinary keys from `<absolute-workspace-root>/.rocketclaw/config.local.yaml`, then `config.yaml`: first active valid scalar wins; empty/invalid continues; lists/maps replace the whole key. `docs_root` remains config.yaml-only. Evaluate `cross_model_review_mode` first: `auto` default, `off` skips unless the live user explicitly opts in. A user prohibition always wins.

Resolve recipient preference: live user > `cross_model_peer` > active project instructions > first available attestably different family in codex, claude, grok, antigravity order. Preserve explicit cursor/composer/opencode preferences rather than silently substituting. `cross_model_model` and `cross_model_effort` use the same layers, overridden by live user intent. Use `opencode.models` to resolve exact available provider/model IDs and offered reasoning variants. Preserve configured choices and tiers: Claude Opus/Antigravity high; Codex/native Grok extra-high; Cursor Grok high/fast and Composer fast are route intent, not permission to invoke another harness. An unavailable exact route/model/variant is disclosed as unmet, never replaced silently. The antigravity default requests Gemini 4 Argon, with one pre-send Flash fallback only when Argon is unavailable and no explicit model was configured. Other observed obsolete/unavailable defaults may use the closest same-family replacement with a new disclosed binding; explicit pins never change.

`CROSS_MODEL_PEERS`, when nonempty, restricts every recipient and intermediary. Cursor/composer aliases allow Cursor, not Grok alone; antigravity requires its literal token, not gemini. Native dispatch must not invent an intermediary to emulate a missing legacy route. Attest the parent serving model from runtime identity, not environment markers or self-report. Unknown identity means independence unverified.

Preserve the editorial default IDs as selection intent: codex `gpt-6-luna` xhigh; claude `claude-opus-5-5` high; native grok `grok-4.7` xhigh; Cursor Grok `grok-4.7[context=256k,reasoning_effort=high,fast=true]`; Composer `composer-2.5[fast=true]`; Antigravity `gemini-4-argon` high, default-only fallback `gemini-3.8-flash`. Resolve native provider IDs and offered variants through `opencode.models`; unavailable legacy preset/recipient semantics are incomplete rather than silently approximated. Native opencode auto may inherit only under the model-policy rule above and never proves different-model identity.

Use a 1200-second hard budget inside the 1210-second collection deadline and a 480-second idle budget only where the native runtime provides reliable activity evidence. Preserve `CROSS_MODEL_HARD_SECS`, `CROSS_MODEL_IDLE_SECS`, `PEER_MAX_TURNS` (default 25), and `CROSS_MODEL_LARGE_DIFF_MAX_TURNS` (40) as bounded configuration intent; do not invent unsupported controls. The collection deadline derives from the configured hard budget plus ten seconds, shared across retries. Disclose unsupported runtime bounds.

Bind scope and trust limits: read-only, no edits, no nested agents, no web, no unrelated file reads. No filesystem polling jobs or shell harness dispatch bridges.
