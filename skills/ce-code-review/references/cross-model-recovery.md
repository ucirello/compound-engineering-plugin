# Native reviewer recovery

Classify observed native errors before recovery; do not guess from a missing result:

- **Permission/tool denial or unconditional prohibition:** stop that operation. No shell, elevation, alternate harness, session or model workaround. Record lost coverage.
- **Missing native tool:** report unavailable. A permitted inline/parent read can contribute attributed evidence only where the review contract allows it, never independent coverage.
- **Model/variant rejection:** distinguish from permission and nesting. Keep explicit pins; resolve a same-family replacement only when the contract permits, disclose before sending. If optional overrides are forbidden, omit the model argument and inherit; disclose unmet tier and independence. Required cross-model coverage remains incomplete.
- **Actual depth limit:** discover effective depth via supported OpenCode config discovery; report nesting, not model or permission failure. Do not evade by shell/session. Installation requires users merge `experimental.subagent_depth >=3` into existing discovered opencode.json(c), preserving siblings/higher values and avoiding competing configs; never change host settings during review.
- **Capacity:** queue rejected launches; collect/release active work and retry while budget remains. Do not shrink the roster or mislabel capacity as failed review.
- **Provider quota/auth/network/overload:** record a started provider failure, not a clean skip. Retry only a new plausibly recoverable condition within the shared deadline; stop repeated errors. Same route/model/scope retains disclosure. A replacement recipient requires explicit re-resolution, allowlist check and fresh disclosure; never automatic egress expansion.
- **Malformed/untrusted artifact:** do not fold. Preserve diagnostics, mark degraded. Never bypass containment/ownership checks.

No-launch failures are resolved before the local roster is final: retain one local adversarial fallback if allowed. Started failures are collected and stopped before any replacement; never run both on the same brief. A same-model native fallback can cover the adversarial lens where allowed, not cross-model independence. A parent inline fallback is not an independent read; focused requires a usable separately dispatched read, otherwise Not ready. A full review may finish with explicitly degraded optional corroboration, but must not claim required independent coverage complete.

Use native terminal delivery/bounded waits only. Preserve pins, exact endpoints, persona, constraints, scope, receipts and read-only limits through recovery. Every successful launch must reach a recorded terminal state before returning. Final Coverage names attempted/requested/actual identity, error class, fallback, unmet tier/depth/independence, and whether the lens ran. Finish leaves never initiate recovery dispatch.
