# Native cross-model recovery

Keep the fixed target, model, effort, adversarial brief, read-only boundaries and exact captured base/head range. Never recover through another harness or a direct Git command. All recovery evidence stays in the workspace-local `.tmp/` run directory.

- **Never started:** scope/config/allowlist/identity constraints, a missing native tool, permission denial, forbidden model override, or exhausted runtime depth are named separately. Retain the local adversarial persona if no peer launched. Suitable inherited-model reviewers may cover the lens when permitted, but do not satisfy required cross-model independence. Record missing required coverage as incomplete.
- **Infrastructure failure before launch identity:** one bounded retry of the same native route is allowed only for a clearly transient new failure, before finalizing the local roster and within the shared deadline. No retries of denied operations, unavailable depth, rejected model arguments or trust failures.
- **Launched then failed:** collect/cancel the original native job to terminal first. A single same-route transient recovery may run within the original remaining deadline, preserving scope and constraints. Stop on a repeated error, exhausted budget, malformed/untrusted artifact or unresolved launch identity. If the local adversarial reviewer was already removed from the roster, restore it only when its native launch is permitted and collect it; otherwise mark the adversarial lens degraded as well as cross-model corroboration incomplete.
- **Overload:** at most one same-route retry for an actual provider overload, inside the same total deadline; no repeated retries or hidden recipient changes.
- **Quota/authentication/unavailable model:** record the actual error. A different route requires fresh permitted resolution and disclosure before any content transfer; it is never an automatic substitution. Preserve explicit configured intent and report unmet requirements.

Allowed inline or parent-coordinator fallback exists only where the review contract permits it. Do not pretend inline work is an independent reviewer. Focused depth requires its independent read; if unavailable, report incomplete coverage, not fully verified.

Use the actual terminal error to distinguish missing tool, depth/capacity, permission denial, model-argument rejection, infrastructure failure and provider failure. DNS/authentication errors do not prove a sandbox policy; never unset environment markers to bypass policy. Do not escalate or invoke another harness to evade a denial.

Bind any recovered artifact to the same run, native launch identity and exact scope; validate schema, containment and size before fold-in. Fold findings once, promote agreement only with attested different-model independence, and keep requested/actual model and effort separate. Preserve failure receipts in final Coverage even when the local lens recovers. Stop/cancel and collect every started job before returning; copy/read back required evidence before removing only its owned disposable job directory. Incomplete cancellation or cleanup is a reported blocker, never an excuse to force-delete state.
