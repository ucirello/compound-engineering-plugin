# Choosing the model for a spawned subagent

Read this before every reviewer dispatch. Use OpenCode native subagents and `opencode.models` to resolve exact available model IDs and effort variants; never another harness dispatcher. Keep the parent on its session model.

The step's tier is the default intent: cheapest capable coherence reviewer, mid-tier design/scope/lite reviewers, and parent or established high-capability judgment reviewers. Preserve configured choices: read `.rocketclaw/config.local.yaml`, then `config.yaml` from the absolute root returned by `jj workspace root`. First active valid scalar wins; empty/invalid scalar continues to the next layer; a present list/map replaces that entire key. `docs_root` remains config.yaml-only. `review_subagents` maps harness names (`codex`, `claude`, `grok`, `cursor`, `opencode`, `antigravity`) to optional string `model` and `effort` fields; apply the current OpenCode entry. User instructions outrank config, which outranks default intent.

Delegation permission, model-override permission, and available nesting depth are separate. This skill explicitly requests reviewer subagents: under a user-OR-skill delegation rule that suffices without a second approval. Respect unconditional prohibitions, unavailable tools, and actual denials. If model overrides require an explicit user model request, omit `model` and effort overrides unless permitted; use suitable inherited-model reviewers and disclose unmet tier intent. Configuration alone is not that user request. Same-model reviewers are separate reviewers, not cross-model independence.

Classify actual errors: permission denial (stop, no retry/bypass), model/effort rejection, concurrent capacity backpressure, missing tool, or exhausted nesting depth. A model rejection may receive one inherited-model retry only if permitted and suitable; never retry a denied call. Queue concurrency-limited reviewers while capacity can recover. Depth is not concurrency: do not repeatedly retry it or evade it through shell/another harness. Where the contract permits inline fallback, label it honestly; otherwise report incomplete coverage, especially for required independence or fixed-model requirements. Collect all started reviewers before returning. Do not change host configuration to overcome a limit.
