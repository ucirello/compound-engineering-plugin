# Cross-model recovery

Use the native dispatch and fixed-route contract in `cross-model-review.md`.

- Conditions-not-met skips (not selected, disabled, remote scope, unknown host family, no permitted independent route) are not dispatch errors. Keep the local adversarial lens when no peer launched; cross-model corroboration remains unavailable.
- A failure before any native launch receipt may receive one corrected retry only for a genuinely recoverable invocation problem. Keep the same recipient/model, exact captured JJ base/head range, read-only brief, and shared deadline. Do this before finalizing the local roster. If it cannot launch, retain the local adversarial reviewer; never launch it and a late peer on the same brief accidentally.
- A successful launch followed by a terminal error is a reviewer failure. Collect it through the native tool. At fold-in, do not re-run a peer if the local adversarial reviewer already covered the brief. If the peer replaced the local lens, report that lens degraded unless a permitted independent recovery completes.
- One provider-overload retry may use the same sanctioned route within the original 1210-second deadline. Keep every retry bounded and stop on repeated failure. A quota-recovery route must be freshly resolved and disclosed before sending content, stay permitted by `CROSS_MODEL_PEERS`, and retain scope and trust boundaries. Never change an explicit model silently.
- Genuine permission denial, model-selection prohibition, and exhausted nesting depth are different failures. Do not retry denied operations or evade depth through shell or another harness. This skill explicitly requests reviewers under a user-or-skill permission rule; that does not override higher-priority prohibitions or confer model-override permission.
- An inherited-model reviewer is allowed only when it meets the lens requirements. It is a separate reviewer, not proof of cross-model independence. Required but unavailable different-model or fixed-route coverage stays incomplete.

The peer may read the exact staged diff and repository context relevant to that range. It may write only its local run artifact and identity receipt. Edits, network research, nested agents, commits, pushes, and PR mutations remain prohibited. Do not loosen read-only controls to make recovery succeed. Stop/collect all launched work before returning. Record actual error class and lost coverage truthfully, retaining recovery evidence under workspace-local `.tmp/`.
