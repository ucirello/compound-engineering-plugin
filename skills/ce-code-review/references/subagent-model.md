# Native subagent permission, model and depth

Read before every first spawn, including lite checks, reviewers, leaves and validators. This skill explicitly requests these reviewer delegates: that satisfies a host user-OR-skill delegation exception; do not ask redundant approval. Actual higher-priority prohibitions, denied tools and unavailable native tools still win. Do not evade them through another harness, shell dispatcher, alternate tool, or retries of denied operations.

**Model permission is separate.** The orchestrator retains its session model. Record each role's intended default tier (session for correctness/security/adversarial; balanced mid-tier for other personas; cheapest capable for trivial checks), overridden by active user/project intent then role configuration. Resolve available exact IDs and variants using native `opencode.models`; task wording does not select a model. Where host policy requires an explicit user model request, omit the optional model argument absent such a request, even when the skill/config names a model. Inherit if suitable and disclose unmet configured tier/model/effort; inheritance is not cross-model independence. Never silently change an explicit pin.

**Role configuration.** Read `review_subagents` from `.rocketclaw/config.local.yaml`, then `config.yaml` in the absolute target workspace root. First active valid value wins; empty/invalid scalar continues to the next layer/default. A present map/list, including empty, replaces the whole key. `docs_root` is config.yaml-only. The role key maps harness compatibility names (`codex`, `claude`, `grok`, `cursor`, `opencode`, `antigravity`) to optional string `model` and `effort`; only the current `opencode` entry applies. Missing/non-string fields keep default intent. Pass effort only if the native tool supports the discovered variant and host permission allows it; otherwise record it unapplied.

**Refusals are distinct.** Classify actual errors as permission, model/effort availability, nesting depth, active-agent capacity, invocation, or tool availability. No retry on permission/tool denial or depth. Model unavailability permits at most one suitable inherited-model retry only when policy and the review contract allow it; record requested and offered IDs, and lost independence. Active-agent capacity is backpressure: collect/release owned agents and retry queued launches when slots free, dropping none. No unsupported operation or another-harness escape. Parent inline fallback is allowed only where the path permits, is attributed parent evidence, and cannot satisfy mandatory independence.

## Required user setup (documentation only)

Users must merge `experimental.subagent_depth >= 3` into their existing **global** `~/.config/opencode/opencode.json` or `opencode.jsonc`. Locate the actual active path with `opencode debug paths` (or `opencode debug paths config`). Edit the existing file, not a competing JSON/JSONC file; preserve a higher existing integer plus all unrelated and sibling config. Plugin/package config alone does not enable nesting. Ensure higher-precedence configuration does not lower the effective value. Never modify host/global config from this skill. If nesting is currently refused, report the exact depth failure and incomplete coverage; setup is not permission and permission is not depth capacity.
