# Watch scheduling and durable state

Use native OpenCode shell/wait tools to run and await the retained deterministic `scripts/pr-snapshot watch` helper, not another harness's dispatcher. The agent owns classification and mutation decisions; the helper fetches/diffs and emits `BABYSIT_WAKE` only for work or a stop. Keep one active writer and watcher. About 150 seconds is an active poll cadence; widen quiet polling to 5–10 minutes and honor rate-limit reset headers. Never busy-spin or use an unmanaged detached process. If native waiting cannot sustain the session, report checkpoint/paused mode with the exact resume invocation. Starting or re-arming authorized monitoring needs no additional approval, but explicit opt-outs and watch/checkpoint boundaries remain binding.

```bash
(cd "$workspace_root" && python3 "$SKILL_DIR/scripts/pr-snapshot" watch --pr <N> --repo <host>/<owner>/<repo> --state-dir "$STATE_DIR" --interval 150 --invocation-id "$RUN_INVOCATION_ID" --session-started-at "$RUN_STARTED_AT" --invocation-budget-seconds "$RUN_BUDGET_SECONDS")
```

Use the host's managed background/wait mechanism for that command. Each wake returns to one semantic tick and then re-arms unless a true stop or transition applies. Compare wake generation with a fresh snapshot; coalesce stale wakes and do no action if attention has cleared. `invocation-superseded` terminates without a re-arm. Ordinary arms leave `--settle-seconds` and `--feedback-coalesce-seconds` unset (300/180 defaults). Set a wider settle only after the review judgment rejects a merge-ready wake. `review-evidence-moved` requires fresh judgment rather than sleeping out obsolete evidence. External approval drains use `--blocked-external-drain-seconds` per `settle.md`. `--downstack-pr <N>` probes each included open lower layer; return to the lowest reopened layer. After mutation snapshot only at the next tick, not mid-tick.

## Journal and invocation fencing

The helper persists `state.json` under the workspace-local ignored `.tmp/rocketclaw/babysit-pr/<host>-<owner>-<repo>-<N>/`. Host is mandatory to separate Enterprise/public PR identities. Its bounded locking, atomic writes, recovery receipts, process identity checks, and invocation fencing remain authoritative; never write a parallel ledger. The journal records PR identity, exact head SHA, snapshot observations, per-item dispositions, dispatched check keys by head, complete typed human decisions and answers, branch-currency claims/outcomes, trajectory, readiness-bearing last-change time, and invocation ID/start/budget/generation. Preserve source identities and actual human answers, not inferred summaries.

The newest invocation with a successful complete first read owns the watcher; a failed preflight cannot displace a healthy watcher. Fence stale writes and wakes by invocation/generation. Superseded watchers terminate without re-arming. Re-arming does not renew the budget or settle clock. Stack transitions carry the same invocation, start, budget, posture, and accumulated suspended/dead time into the next layer's state. Persisted-state age is not invocation runtime. Default interactive budget is 8 active hours with a 3-calendar-day wall backstop; report which ceiling was hit and measured active runtime. Never automatically renew it.

## Claim, act, confirm

Observing work does not mark it handled. Record review/check completion only after action succeeds. An unresolved thread reopens on new reviewer evidence. Dispatched top-level/review-body candidates stay handled across edits (status bots rewrite them); a new comment ID is new work. Frozen decision evidence changing instead invalidates the whole decision. Head movement clears SHA-scoped CI dispatch state. Legacy incomplete residuals fail open to ordinary actionable work.

Keep one canonical human-decision set across review, CI, and currency. Freeze complete typed residuals and exact source observations, and re-read covered threads after replies. Only a recorded exact human response to its decision ID answers it; comments, reruns, edited feedback, and head movement never implicitly answer. Changed/disappeared observations invalidate the whole grouped decision and reopen surviving sources. Answers remain associated with matching observations until acted on. Independent streams continue while a current decision blocks readiness and advancement. Pipeline returns the canonical set once autonomous work is exhausted.

Before external currency mutation, lock and claim the exact head/base-bound item, then revalidate remote OIDs immediately. A claimed item's re-entry is reconciliation-only. Record `mutation-observed`, `proven-no-mutation`, or `ambiguous`; allow exactly one backed-off retry only with conclusive no-mutation proof. Ambiguous outcomes never resubmit. Confirmation requires ancestry and current remote evidence, not head movement alone. See `branch-currency.md`.

## Readiness and stop handling

Use GitHub's complete current checks/review policy and certain `MERGEABLE`/`CLEAN` state, plus no base/stack/currency blockers, no backlog or current residual, and review judgment in `settle.md`. Bind live base identity independently to the generated test merge's head/base parents. Failed/racing/pending identity blocks readiness; a historical base difference alone does not. An absent generated merge for `DIRTY` can still support a conflict item when independent live-base reads match. The helper queries the REST ref first. Only REST 404 permits its bounded noninteractive read-only `git ls-remote` fallback authenticated through `gh auth git-credential`: JJ fetch would mutate repository state and is not an equivalent independent remote query. This narrow fallback authorizes no other Git workflow operations. A stable race solely in the generated merge's base parent may degrade to disclosed `stale-computation` under the helper's existing bounded policy without restarting the quiet clock.

Track changes in checks, feedback identities, head, review decision, mergeability, and merge state to reset the quiet clock. Default merge-ready settle is 300 seconds; it is evidence of cooling, never proof no review will arrive. A changed evidence set invalidates a widened settle decision. Apply the bounded review-still-expected and external-approval drain policy in `settle.md`. Never approve gated CI.

Terminal/settled/budget/user stops end interactive monitoring. Needs-human, blocked-failing, and stack-blocked residuals remain visible while independent interactive work continues. Pipeline instead returns when autonomous progress ends, never waiting on human decisions or settle; cap repair at 3 CI fix rounds per lineage and about 30–45 minutes, returning running/red checks as residuals. Success requires nonempty sufficient check evidence, all checks OK, certain CLEAN mergeability, no actionable backlog, canonical residual, base/stack/currency blocker, or unrequested base merge.

Read `stack.md` for one-target continuation, downstack reopening, and landing. Return to the lowest reopened included layer, never mutate two concurrently. External head changes require fresh evidence, never overwriting pushed work. No push access or unknown authority requires safe handback. Keep reports truthful: settled is not merged, and looks ready is the user's merge decision outside explicit `stack-land` authorization.
