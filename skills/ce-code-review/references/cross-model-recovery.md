# Native peer recovery and coverage

Keep the captured base/head, target, model, tier, persona, read-only boundary and deadline fixed. A no-launch failure is classified before finalizing the roster; a launched-then-failed peer is collected and stopped/released before replacement. Do not run duplicate adversarial reviewers unknowingly or fold an artifact twice.

Retry a transient infrastructure failure only while the shared 1200-second default (`CROSS_MODEL_HARD_SECS`) budget remains, the failure is new and plausibly recoverable, and the host permits it. Stop on a repeated failure. Never retry a permission denial or evade a nesting limit/model restriction. Preserve diagnostic evidence under the local `.tmp/` run directory. Quota/unavailable-model failure does not authorize recipient substitution: a new route requires the same configured allowlist, model-selection permission and disclosure checks as the first route.

When native delegation is permitted and a suitable inherited-model adversarial reviewer is available, it may cover the lens without an optional model override. Record `adversarial lens: in-process fallback (cross-model peer not run: <actual reason>)` and `peer.outcome: in-process-fallback`. That is not cross-model independence. If the contract requires a different model/fixed route, record that requirement as incomplete even when the ordinary lens ran. Never label this `harness-native fallback`, which is the caller's distinct signal for bypassing this skill.

An allowed inline or parent-coordinator fallback must preserve independence required by its contract; otherwise report missing coverage. Genuine delegation prohibition, exhausted nesting capacity, missing tool and rejected model argument are different outcomes and must be reported accurately. Review invocation alone does not override host policy. Do not use another harness or shell dispatch to work around it.

All reviewer inspection remains non-mutating. Use native JJ diff/file/history operations from the absolute target workspace root, and `GIT_DIR=$(jj git root)` for repository-scoped `gh`. No direct Git execution, web access or project mutations are implied by reviewer delegation. Stop live workers and release native resources before returning; keep failure artifacts and recovery evidence rather than deleting them. Completed review requires every mandatory pass or an explicitly reported incomplete gate.
