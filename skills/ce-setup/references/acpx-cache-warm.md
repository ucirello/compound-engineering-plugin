# Native model cache readiness

Retain cache diagnostics without downloading another harness's transport or adapters. Native OpenCode manages provider connections and model metadata; discover configured models with `opencode.models` and report provider authentication or model availability problems without claiming a cache warm succeeded. Do not install ACP transports, invoke peers to warm caches, or change user-global caches. Keep pack caches under the absolute workspace `.tmp/packs` and preserve reusable completed entries. A missing provider is not delegation denial or exhausted nesting capacity.
