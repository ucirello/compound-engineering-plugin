# Cross-Model Judgment Pass

Run only for activated `adversarial-document-reviewer`, `product-lens-reviewer`, or `security-lens-reviewer` lenses. This pass is additive and non-blocking; unavailable coverage must be named, never represented as verified.

## Policy and native route resolution

Read `.rocketclaw/config.local.yaml`, then `config.yaml` at the absolute root returned by `jj workspace root`. First active valid scalar wins; empty or invalid scalars continue to the next layer; lists/maps replace the whole key, including empty values. `docs_root` remains config.yaml-only. Missing configuration is allowed, including reviews outside a repository.

Evaluate `cross_model_review_mode` first: `auto` is the default; `off` skips the automatic pass unless the user explicitly requests it in conversation. Record **disabled by checkout config** distinctly. A live prohibition always wins.

Resolve desired target from conversation, then `cross_model_peer`, then active project instructions, then the first available attested-different family in `codex → claude → grok → antigravity`. Preserve these operational family preferences: Codex/OpenAI, Claude/Anthropic, Grok/xAI, Antigravity/Gemini, and explicitly requested Composer or Cursor routes. Use `opencode.models` to resolve available exact provider/model IDs and variants, then native OpenCode subagents. Do not invoke another harness, ACP adapter, or deleted bridge helper. A fixed harness/intermediary requirement unavailable natively is an unmet route, not permission to substitute.

Read `cross_model_model` and `cross_model_effort` with the same config precedence; conversation overrides them. Desired tiers remain high reasoning, except Codex and native Grok extra-high, Cursor Grok high/fast, and Composer fast. Preserve explicit choices exactly; disclose unsupported choices rather than silently substituting. Model-selection permission is independent of delegation permission: follow `dispatch.md`. If optional model overrides are forbidden absent an explicit user model request, omit `model`; an inherited-model reviewer can supply ordinary evidence but cannot satisfy a required different-model pass. Configuration alone does not authorize that override.

Attest the host's actual serving family using runtime evidence, not a requested model or harness brand. An unknown family cannot establish automatic cross-model independence. `CROSS_MODEL_PEERS`, when set, restricts recipients; unset means unfiltered, not a waiver of host permissions. Never add an intermediary or silently change recipients. Before dispatch, disclose the requested exact model, effort, native route, provider recipients, and that document content leaves the machine. In non-interactive mode record that disclosure in the run evidence without asking a user question. Requested model identity is not proof of served identity.

## Dispatch and collection

Apply the delegation/model/depth checks in `dispatch.md` to actual native dispatch. No permission workaround or shell escape is allowed. Use bounded parallelism alongside ordinary personas. For each activated trio lens, seed a fresh read-only reviewer with the same persona and document slice its in-process twin receives; legacy documents use the full document. Also dispatch exactly one `whole-doc` reviewer with `personas/whole-doc-reviewer.md` and the full document. If it cannot run, name the lost broad coverage separately. Peers receive round-1 framing, not the accumulated decision primer.

Use native least-privilege restrictions: no edits, shell execution, further delegation, or unrelated context. Supply document content and schema directly. If the native runtime cannot enforce the required isolation, report the pass unavailable rather than claiming a tool-less sandbox. Any scratch slices or results belong under the target workspace's absolute `.tmp/rocketclaw/ce-doc-review/<run-id>/`; outside a JJ repository use local `.tmp/`. Ensure `.tmp/` is ignored in repository `.gitignore`; reject unsafe symlinks or ambiguously owned directories. Never use OS temporary fallbacks.

Collect every started native subagent to a terminal outcome within the configured `CROSS_MODEL_HARD_SECS` budget (default 1200 seconds), respecting host cancellation and lifecycle APIs. Distinguish permission denial, optional-model rejection, missing tools, depth exhaustion, transient capacity, provider failures, and timeouts using actual errors. Never retry denied operations, evade depth limits, or automatically restart quota failures. A recoverable invocation correction must preserve recipient, scope, isolation, and deadline; changing recipients requires fresh resolution and disclosure.

Validate returned `findings-schema.json` content; normalize `reviewer` to `<reviewer-name>-<provider>` and downgrade peer `safe_auto` to `gated_auto`. Retain requested and actual model/route evidence separately. Set `independence_verified: true` only with attested different serving families and a fresh independent context; same-model reviewers are separate reviewers, not cross-model corroboration. Without verification, retain attributed evidence but do not promote agreement. Whole-doc findings can corroborate any merged in-process finding under synthesis's one-fix rule.

Name every owed but unavailable lens, whole-doc sweep, failed/timeout outcome, and unmet model/tier/route requirement in Coverage and the structured non-interactive result. Empty findings mean no additional issues, not proof a missing pass ran. Provider authentication claims require a provider-capable launch or response; do not infer an account logout from sandbox-shaped errors. Optional cross-model loss does not block ordinary synthesis, but the cross-model coverage remains incomplete.

Before return collect all outcomes, release only agents this run owns through supported native lifecycle calls, and preserve failure evidence. Remove consumed scratch only with ownership and authorization established; on cleanup failure retain state and report the blocker. Never delete unrelated or still-needed content.
