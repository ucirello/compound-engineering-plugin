# Native adversarial recovery

Classify observed outcomes, not guesses about host brands:

- **Policy denial / actual permission rejection:** stop that dispatch; no retry, alternate harness, shell workaround, or fresh recipient. Record denied coverage. The loaded skill requests delegation under user-or-skill permission, but cannot override unconditional policy.
- **Missing native tool:** record unavailable; do not substitute another harness dispatcher.
- **Depth limit:** distinguish from denial. Discover package and consuming effective configuration; document merging `experimental.subagent_depth >=3` into the existing global OpenCode JSON/JSONC (locate with `opencode debug paths`), preserving siblings/higher values. Do not modify host configuration. Parent inline evidence is not independent coverage.
- **Capacity/backpressure:** collect and release owned active reviewers using native lifecycle, then retry the queued reviewer within the same bounded budget; do not drop roster entries or mislabel capacity as denial.
- **Model/variant rejection:** preserve requested provider/model/effort in the receipt. Discover with `opencode.models`; a user-required explicit route is not silently replaced. If overrides require user request, inherit for ordinary reviewers and disclose unmet configured routing. Delegation permission is not override permission.
- **Transient provider overload or native dispatch infrastructure failure:** at most one same-route retry within the original shared deadline, preserving exact endpoints, identity, prompt, recipient and permissions. Repeated failure, malformed JSON or timeout is terminal; stop/release owned work. Never retry denial.

If the peer did not yield usable adversarial coverage and no adversarial reviewer already ran, dispatch exactly one inherited-model generic adversarial reviewer when policy and native tooling permit. Give it the original brief, never another reviewer's conclusions. A same-model fallback covers a separate adversarial read but is not cross-model corroboration. If this fallback is unavailable, focused depth returns Not ready and full depth names lost adversarial coverage. An explicitly required cross-model pass remains incomplete regardless of fallback. Inline parent analysis may contribute attributed evidence only where the contract allows it; never call it independent or silently award complete coverage.

No failed launch disappears into a clean skip. Preserve exact launch identity, failure class, retry count, terminal state, requested and observed model/effort, and unassessed scope in `peer.outcome`, `peer.artifact`, `peer.coverage` and final Coverage. Config-disabled or ineligible scope is not run; started failure is degraded. Release owned launches before returning, retaining receipts and recovery evidence under workspace-local `.tmp`.
